Elliott Wave (`mod_elliott.py`)
Basado en "Elliott Wave [LuxAlgo]", © LuxAlgo:
https://es.tradingview.com/script/KvrhsPTp-Elliott-Wave-LuxAlgo/
Cambios: reescrito de Pine Script a Python; se eliminaron los dibujos, las líneas de Fibonacci y las
señales de cruces; se usan solo velas cerradas; el código alcista y bajista se unificó; los círculos se envían a Telegram.
Smart Money Concepts (`mod_smc.py`)
Basado en "Smart Money Concepts", © LuxAlgo (TradingView, CC BY-NC-SA 4.0).
https://es.tradingview.com/script/CnB3fSph-Smart-Money-Concepts-SMC-LuxAlgo/
Cambios: reescrito de Pine Script a Python; solo se conservaron las alertas de Swing Structure (BOS / CHoCH) y de
Swing Order Blocks (ruptura); se eliminaron la estructura interna, los order blocks internos, EQH/EQL, FVG,
zonas premium/discount, niveles multi-timeframe y todos los dibujos; se usan solo velas cerradas.
Supertrend (`mod_supertrend.py`)
Port en Python del indicador Supertrend de TradingView (`ta.supertrend`, ATR 10, factor 3.0), con el algoritmo
estándar publicado en la documentación de Pine Script. Solo alerta el cambio de tendencia, con velas cerradas.
